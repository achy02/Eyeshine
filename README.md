# 👁️ Eyeshine

Eyeshine is a cross-platform application designed to assist visually impaired users by leveraging computer vision and machine learning to detect and describe objects in real time.

---

## 🧠 Overview

**Eyeshine** empowers visually impaired individuals by providing real-time object detection and feedback. Using a mobile device's camera, the app identifies surroundings and delivers audible or textual descriptions to improve situational awareness and independence.

---

## ⚙️ Features

- 🎯 **Real-Time Object Detection** – Detects and identifies objects using the device camera.
- 🗣️ **Descriptive Feedback** – Converts object detection into useful auditory or textual cues.
- 📱 **Cross-Platform Support** – Developed with Flutter to run on Android and iOS.
- 🚀 **Performance Optimization** – Uses C++ modules for speed-critical tasks.

## 🚀 Getting Started

### ✅ Prerequisites

- Flutter SDK: [Install Flutter](https://flutter.dev/docs/get-started/install)
- CMake: [Install CMake](https://cmake.org/download/)
- Dart SDK: [Get Dart](https://dart.dev/get-dart)

---

### 🔧 Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/achy02/Eyeshine.git
   cd Eyeshine
   ```

2. **Install dependencies**:
   ```bash
   flutter pub get
   ```

3. **Build the project**:
   ```bash
   flutter build apk      # For Android
   flutter build ios      # For iOS
   ```
